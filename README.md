# Portfólio de Ciência de Dados

Este repositório reúne projetos de Análise de Dados e Ciência de Dados
desenvolvidos com foco em resolução de problemas de negócio, modelagem
preditiva e visualização de dados.

## Sobre Mim
Sou formado em Administração e pós-graduado em Ciência de Dados e IA (Lato Sensu).
